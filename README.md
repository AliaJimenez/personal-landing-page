# Personal Landing Page 🚀

Página web personal y perfil profesional interactivo desarrollado con **HTML5** y **CSS3** puro. Presenta un diseño moderno con componentes estilo terminal/código, tipografía tipográfica cuidada y diseño adaptativo a dispositivos móviles.

---

## 🎨 Características

- **Diseño Estilo Terminal / Editor**: Componentes visuales inspirados en la estética de desarrollo (estilo de ventanas con controles chrome y fuente `JetBrains Mono`).
- **100% Responsivo**: Layout adaptable mediante CSS Grid y Flexbox.
- **Paleta de Colores Oscura**: Variables CSS para un tema oscuro elegante y contrastado.
- **Integración Multimedia**: Marco para foto personal con fallback inteligente e incrustación de video de YouTube.
- **Cero Dependencias**: Sin librerías ni frameworks pesados de JavaScript; solo HTML semántico y CSS nativo[cite: 1].

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica[cite: 1].
- **CSS3**: Variables CSS, CSS Grid, Flexbox, y `@media queries` para diseño responsivo[cite: 1].
- **Google Fonts**:
  - *Fraunces* (Encabezados)[cite: 1]
  - *Inter* (Texto principal)[cite: 1]
  - *JetBrains Mono* (Estilo código/terminal)[cite: 1]
