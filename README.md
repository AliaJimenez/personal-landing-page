# Personal Landing Page 🚀

Página web personal y perfil profesional interactivo desarrollado con **HTML5** y **CSS3** puro. Presenta un diseño moderno con componentes estilo terminal/código, tipografía tipográfica cuidada y diseño adaptativo a dispositivos móviles.

**EN** — Personal landing page built with pure HTML5 and CSS3: terminal/code-editor inspired design, dark theme with CSS variables and a fully responsive layout.

🔗 **Live demo · Demo en vivo:** https://aliajimenez.github.io/personal-landing-page/

---

## 🎨 Características

- **Diseño Estilo Terminal / Editor**: Componentes visuales inspirados en la estética de desarrollo (estilo de ventanas con controles chrome y fuente `JetBrains Mono`).
- **100% Responsivo**: Layout adaptable mediante CSS Grid y Flexbox.
- **Paleta de Colores Oscura**: Variables CSS para un tema oscuro elegante y contrastado.
- **Integración Multimedia**: Marco para foto personal con fallback inteligente e incrustación de video de YouTube.
- **Cero Dependencias**: Sin librerías ni frameworks pesados de JavaScript; solo HTML semántico y CSS nativo.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Variables CSS, CSS Grid, Flexbox, y `@media queries` para diseño responsivo.
- **Google Fonts**:
  - *Fraunces* (Encabezados)
  - *Inter* (Texto principal)
  - *JetBrains Mono* (Estilo código/terminal)

## 🚀 Run · Ejecutar

No build step needed: open `index.html` in your browser, or serve the folder locally.
*No requiere compilación: abre `index.html` en el navegador o sirve la carpeta localmente.*

```bash
npx serve .
```
